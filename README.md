# 博客文集

2005–2011 年新浪博客的离线存档，共 350 篇、653 张图片。

本站是一个完全独立的静态页面：没有框架、没有外部脚本、没有 CDN 依赖。
`index.html` 内已包含全部文字与检索功能，图片放在 `images/`（正文）与 `thumbs/`（缩略图）。
直接双击 `index.html` 即可离线浏览，无需服务器。

| 目录 | 内容 |
|---|---|
| `index.html` | 全站（正文、时间轴、搜索、相册、系列） |
| `images/` | 653 张正文图片 |
| `thumbs/` | 653 张缩略图 |

原博客：blog.sina.com.cn/songyang1106
